Announcer Audio

Speaks each line aloud as it streams in, so you can race without reading the overlay. Uses your Mac's built-in voices — no extra API cost and no network round trip. The volume_up button in the main window mutes it quickly.

Tip: Apple's free Enhanced/Premium voices sound noticeably better at the same speed — System Settings › Accessibility › Spoken Content › Manage Voices.

Getting Started

  1. Get an API key: Sign up at console.anthropic.com and create an API key.
  2. Enter your key: Go to the Claude API tab and paste your API key.
  3. Test connection: Click "Test Connection" to verify your key works.
  4. Choose a style: Select a commentary style preset or create your own.
  5. Start riding: The commentary will automatically update during your ride.

Commentary Styles

  • Professional: Concise tactical analysis focusing on power data and race positioning.
  • Casual: Friendly commentary using cycling slang and community terms.
  • Dramatic: Exciting play-by-play that builds tension and highlights key moments.
  • Tactical Coach: Direct advice on when to attack, who to watch, and how to respond.
  • Custom: Write your own system and user prompts for fully customized commentary.

Cost Information

Claude API pricing (approximate, per 1K tokens):

  • Haiku 4.5: ~$0.001 per 1K input tokens, ~$0.005 per 1K output tokens
  • Sonnet 5: ~$0.002 per 1K input tokens, ~$0.010 per 1K output tokens
  • Opus 5: ~$0.005 per 1K input tokens, ~$0.025 per 1K output tokens

A typical commentary request uses ~500-1000 tokens. With Haiku at 60-second intervals, expect costs around $0.15-0.35 per hour of racing.

Tips

  • Use Haiku for best speed and lowest cost - it's perfect for live commentary.
  • Reduce max tokens for shorter, punchier commentary.
  • Select fewer data fields to focus commentary on what matters most to you.
  • The pause button in the main window stops auto-updates but keeps history.
  • Click copy to share particularly good commentary.
